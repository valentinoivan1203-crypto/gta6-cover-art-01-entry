Neon Nights Cover Studio turns your photos and a caption into multi-panel cover art in the style of GTA 6's posters, with a Vice City sunset or neon colour grade, exported as a PNG in 1080x1080, 1080x1350 or 1920x1080. It runs offline in a desktop browser; your photos never leave your machine.

Load up to three of your own photos (or use the built-in samples), pick a layout — Poster, Grid or Wide — crop and position each panel by dragging it, write the caption, choose a colour grade, and export the PNG. The lettering is Anton, an open font shipped under the SIL Open Font License.

## Run it

```sh
cd app && python3 -m http.server 8080
```

Then open http://localhost:8080 in a desktop browser. Any static file server works; the app makes no network request.
